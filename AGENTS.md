## Docs

The API Reference is generated by autodoc from the docstrings in `pyCE/**/*.py`,
so docstring edits are the only way to change those pages. Build it with the
commands in the Documentation section of `README.md`; the build must finish with
zero warnings.

Docstrings are NumPy-style (napoleon) and carry their equations as real
reStructuredText math: `.. math::` for displayed equations, the `:math:` role
inline. Any docstring containing LaTeX backslashes **must** be a raw string
(`r"""..."""`) or Python eats the escapes and the rendered output is silently
wrong.
